# Neelu ke liye 🌈

## Vercel pe host karna

1. Is folder ko GitHub pe ek nayi repository mein upload karo.
2. vercel.com pe login karo → "Add New Project" → wo repository choose karo.
3. Framework "Next.js" apne aap select ho jayega. Bas "Deploy" dabao.

## Apne computer pe chalana (optional)

```
npm install
npm run dev
```
Phir browser mein http://localhost:3000 kholo.
